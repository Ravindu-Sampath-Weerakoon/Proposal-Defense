\section{PROBLEM AND SIGNIFICANCE}

\begin{frame}{The Technical Dichotomy and Significance}
    \begin{itemize}
        \item \textbf{The Primary Problem:} An unresolved trade-off exists between system latency, user privacy, and template revocability.
        \item \textbf{Efficiency Gap:} Cryptographic tools like Homomorphic Encryption (HE) are too computationally expensive for real-time edge monitoring.
        \item \textbf{Privacy Gap:} High-accuracy Deep Learning models often require storing original behavioral features, making them prone to reverse engineering.
        \item \textbf{Local Template Recoverability:} This research enables "cancelable" biometrics where compromised data is reset by regenerating a \textbf{Keyed-JL Projection Matrix} locally.
        \item \textbf{Significance:} Provides a mechanism to re-issue a fresh behavioral identity on the local computer without requiring the user to change their natural habits.
    \end{itemize}
\end{frame}
