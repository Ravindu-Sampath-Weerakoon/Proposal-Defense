            \vspace{0.5cm}
            \begin{itemize}
                \setlength{\itemsep}{6pt}
                \item \scriptsize \textbf{Privacy-by-Design:} Raw data never leaves the local device, ensuring data minimization.
                \item \scriptsize \textbf{Keyed Transformation:} Uses a secret key $K$ to generate non-invertible templates.
                \item \scriptsize \textbf{Privacy Barrier:} Only projected embeddings ($Z$) cross the network to the server.
                \item \scriptsize \textbf{One-Class Engine:} Deep SVDD detects anomalies without requiring imposter data.
                \item \scriptsize \textbf{Template Revocability:} Compromised identities can be "reset" by local key renewal.
            \end{itemize}
